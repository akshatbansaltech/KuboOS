# KuboOS

A web operating system built from scratch — one HTML file, zero frameworks, zero dependencies. Part of the "make your own OS" workshop mission.

## Run it

Just open `index.html` in any browser. No install, no password, no login.

## Features

- **Lockscreen** — asks your name once, remembers it, greets you with it everywhere (welcome app, start menu, terminal, boot line). No password, just a name tag.
- Multi-window desktop: drag, focus, minimize, maximize, close, corner resize, snap-to-top maximize
- Taskbar with running-app pills and a live clock; start menu (K button) + desktop icons
- Boot sequence with animated loading bar; toast notifications; custom in-OS dialogs
- **Apps**: Notes (localStorage autosave), Calculator (keyboard supported), Terminal (joke/neofetch/sudo), Devlog, About, Welcome
